# 七个习惯教练（7 Habits Coach）

基于史蒂芬·柯维《高效能人士的七个习惯》蒸馏出的 AI 自我教练工具。核心理念：**认知镜子，而非任务管家**——帮你"看见"自己的思维模式和盲区，而不是帮你管理更多待办事项。

> ⚠️ 这是一个基于书籍的独立粉丝作品（fan work），用作者自己的理解重新组织和表达了书中的思想。**与 FranklinCovey 公司或原书作者无任何关系，未经官方授权。**

## 它能帮你什么

| 你的困境 | 教练怎么帮你 |
|----------|-------------|
| 迷茫、不知道自己要什么 | 用"以终为始"帮你找到方向筛选器 |
| 忙了一天但什么都没做成 | 用"要事第一"帮你把大石头先放进去 |
| 总被外界推着走、被动无力 | 用"积极主动"帮你从关注圈拉回影响圈 |
| 和重要的人反复冲突 | 用"知彼解己+双赢思维"帮你先理解再被理解 |
| 倦怠、感觉自己被掏空 | 用"不断更新"帮你检查四个维度的 P/PC 平衡 |
| 团队协作低效、方案僵持 | 用"统合综效"帮你找到第三选择 |
| 打卡式成长、形式大于实质 | 用认知镜子照见真正的改变量 |

## 快速安装

### 方式 1：Claude Code Skill（推荐）

1. 下载本仓库
2. 将整个 `qigexiguan-coach/` 目录放到 Claude Code 的 skills 目录下
3. 在对话中自然描述你的困境，命中触发词后 skill 自动激活
4. 或显式调用：`/qigexiguan-coach`

### 方式 2：ChatGPT 自定义 GPT

1. 打开 ChatGPT → 创建自定义 GPT
2. 将 `GPT_INSTRUCTIONS.md` 的内容粘贴到 Instructions 字段
3. 将 `references/` 目录下的文件上传为知识文件
4. 发布到 GPT Store（可选）

## 设计哲学

- **认知镜子 > 任务管家**：目标是"看见"，不是"做更多"
- **由内而外**：从品格和思维模式入手，不是技巧和话术
- **一个动作 + 一个反思**：每次只给一个能在影响圈内完成的最小行动
- **不打卡、不积分、不排名**：反对把成长异化为表演
- **原则中心**：以不变的原则为锚点，而非即时便利或他人评价

## 使用示例

```
用户：我觉得工作完全是被推着走的，很烦但没办法。

教练：你说"被推着走""没办法"——这些词暗示你把刺激和回应之间的
选择空间跳过去了。今天试试：下次老板给你任务，不要只说"好的"，
多加一句"我先梳理优先级，下午给你确认和其他事的先后顺序"。
```

更多示例见 [`references/examples.md`](references/examples.md)
