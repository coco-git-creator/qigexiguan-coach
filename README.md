# 七个习惯教练 🪞

基于史蒂芬·柯维《高效能人士的七个习惯》的 AI 自我教练工具。

**核心理念：认知镜子，而非任务管家。** 帮你"看见"自己的思维模式和行为盲区——不打卡、不积分、不排名。

> ⚠️ 独立粉丝作品，与 FranklinCovey 公司或原书作者无任何关系。

---

## 能帮你什么

| 你的困境 | 教练怎么帮 |
|----------|-----------|
| 迷茫，不知道自己要什么 | 用"以终为始"帮你找到方向筛选器 |
| 忙了一天但什么都没做成 | 用"要事第一"帮你把大石头先放进去 |
| 总被外界推着走，被动无力 | 用"积极主动"把你从关注圈拉回影响圈 |
| 和重要的人反复冲突 | 用"知彼解己+双赢思维"帮你先理解再被理解 |
| 倦怠，感觉自己被掏空 | 用"不断更新"帮你检查四个维度的平衡 |
| 成长停滞，原地踏步 | 用认知镜子照见真正的改变量 |

## 怎么用

1. 打开网页
2. 输入 DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) 手机号注册 → API Keys → 新建 Key，首次注册有免费额度）
3. 描述你的困境，AI 教练会帮你看见盲区 + 给一个能立刻行动的小动作

> 🔒 Key 只存在你的浏览器里，不上传任何服务器。完全免费使用。

## 设计哲学

- **认知镜子 > 任务管家**：目标是"看见"，不是"做更多"
- **由内而外**：从品格和思维模式入手，不是技巧和话术
- **一个动作 + 一个反思**：每次只给一个能在影响圈内完成的最小行动
- **不打卡、不积分、不排名**：反对把成长异化为表演
