# 《高效能人士的七个习惯》核心框架

## 全局主线

这套 skill 的底层主线是：

```text
看见模式（认知镜子） → 定位成熟度 → 回到影响圈 → 原则中心行动 → 反思照见 → 品格→习惯→命运
```

用户通常不是"懒/弱/差"，而是卡在以下节点：

- 在关注圈打转，忽略了影响圈（习惯一）。
- 没有清晰的个人使命和目标，被紧急的事推着走（习惯二、三）。
- 把人际关系当成"零和游戏"，看不到双赢的可能性（习惯四）。
- 用自传式回应在听，而不是在理解（习惯五）。
- 追求一致性和效率而排斥差异，错过了创造性合作（习惯六）。
- 四个维度（身体/精神/智力/社会情感）失衡，产出透支了产能（习惯七）。

## 成熟度连续体

```
依赖（"你"——你照顾我）→ 独立（"我"——我可以）→ 互赖（"我们"——我们一起）
```

| 阶段 | 关键词 | 需要的习惯 | 典型卡点 |
|------|--------|-----------|---------|
| 依赖 | 被动、等靠要、归因外界 | 习惯一·二·三 | 把问题归咎于环境/他人，缺乏"我可以选择"的意识 |
| 独立 | 自主、负责、执行 | 习惯一·二·三 | 过度独立，不会合作，觉得"别人不如我自己做" |
| 互赖 | 合作、共创、共赢 | 习惯四·五·六 | 把合作理解为妥协，不知道可以"第三选择" |

教练判断：**先确认用户卡在哪个阶段，再选择介入的习惯。**

## 七个习惯全景

### 习惯一：积极主动（Be Proactive）

**核心公式**：刺激 → 选择的自由 → 回应

- 影响圈：我能直接控制或间接影响的事。
- 关注圈：我关心但无法控制的事。
- 主动语言 vs 被动语言："我选择……" vs "我不得不……"
- 暂停按钮：在刺激和回应之间，人有选择的自由。

### 习惯二：以终为始（Begin with the End in Mind）

**核心公式**：任何事物都经过两次创造——先在脑中，再在现实中。

- 个人使命宣言：你希望成为什么样的人？做什么样的事？持有什么样的价值观？
- 以原则为中心：不以配偶/家庭/金钱/工作/享乐/朋友/敌人/自我为中心。
- 葬礼想象：你希望别人在你的葬礼上如何评价你？

### 习惯三：要事第一（Put First Things First）

**核心公式**：重要的事先做，而不是紧急的事先做。

- 四象限：重要-紧急 / 重要-不紧急 / 不重要-紧急 / 不重要-不紧急。
- 第二象限（重要但不紧急）是高效能的关键区域。
- 周计划 > 日计划：以角色和目标组织一周，而不是以事件填充一天。
- "大石头先放"：先为最重要的事留出时间，再填入其他。
- 对不重要的事说"不"。

### 习惯四：双赢思维（Think Win-Win）

**核心公式**：不是你的方式或我的方式，而是更好的方式——更高的方式。

- 六种人际模式：双赢 / 赢-输 / 输-赢 / 输-输 / 赢 / 双赢或不合作。
- 双赢的五个维度：品格（诚信、成熟、富足心态）→ 关系 → 协议 → 体系 → 过程。
- 富足心态 vs 匮乏心态：相信资源足够大家分 vs 觉得别人得到我就少了。
- 情感账户：了解对方、注意小节、信守承诺、明确期望、正直、道歉。

### 习惯五：知彼解己（Seek First to Understand, Then to Be Understood）

**核心公式**：先诊断，再开处方。

- 同理心倾听：站在对方的角度理解，不只是听内容，而是听感受和意图。
- 自传式回应（四种需要避免的回应模式）：建议、探究、诠释、评价。
- 倾听层次：充耳不闻 → 假装在听 → 选择性接收 → 专注地听 → 同理心倾听。
- 理解之后才寻求被理解：Ethos（品格）→ Pathos（情感）→ Logos（逻辑）。

### 习惯六：统合综效（Synergize）

**核心公式**：整体大于部分之和。1+1 > 2。

- 重视差异：差异不是障碍，而是创造力的来源。
- 第三选择：不是你的方案也不是我的方案，而是我们一起创造的更好的方案。
- 统合综效的层次：容忍差异 → 接受差异 → 重视差异 → 庆祝差异。
- 统合综效的敌人：从众、防御、刻板印象、非此即彼的思维。

### 习惯七：不断更新（Sharpen the Saw）

**核心公式**：P（Production 产出）/ PC（Production Capability 产能）平衡。

- 四个维度：
  - 身体：运动、营养、睡眠、压力管理
  - 精神：价值观澄清、使命回顾、冥想/祈祷、自然/艺术
  - 智力：阅读、写作、学习、教学
  - 社会/情感：服务他人、同理心练习、建立关系
- 螺旋上升：学习 → 承诺 → 行动 → 学习（每一圈都在更高层面）。
- 更新是"自我领导"和"自我管理"的底盘。

## P/PC 平衡法则

所有效能都可以用 P/PC 来衡量：

| 故事原型 | 解释 | 教练方向 |
|----------|------|---------|
| 杀鹅取卵 | 只顾产出，透支产能 | 问：你在用什么资源（身体/关系/信任）换短期结果？ |
| 光磨刀不砍柴 | 只顾准备，从不产出 | 问：你准备了多久？什么时候算"准备好"？ |
| 既喂鹅又收蛋 | 在产出和产能间找到节奏 | 这是目标状态 |

## 反模式清单

- 刺激-反应模式：把刺激直接等同于反应，跳过了"选择的自由"。
- 以紧急为重要：用忙碌替代效能，用"我很忙"来证明自己有价值。
- 社会镜映：用别人的评价来定义自己，而非以原则定义自己。
- 输赢思维：凡事必分高下，看不到双赢和第三选择。
- 自传式倾听：对方没说完就开始想怎么回应/建议/评价。
- 效率崇拜：追求"做更多更快"，却从未问"做对了没有"。
- 平衡的幻觉：牺牲一个维度（健康/关系/学习）去换另一个维度的产出。
- 跳级思维：还没独立就追求互赖（结果变成依附）；还没建情感账户就想提要求。
- 工具化关系：把人当手段而非目的。

## Skill 使用边界

这是成长教练框架，基于品格伦理和原则中心。它不替代：
- 临床心理治疗（抑郁、焦虑症、创伤）
- 专业法律或财务建议
- 紧急危机干预（自伤、暴力、虐待）

遇到高风险情况，先引导用户寻求对应的专业支持。
