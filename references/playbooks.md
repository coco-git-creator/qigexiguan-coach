# 可执行教练流程

按用户当前问题选择一个流程，不要一次全用。每次尽量给出"一面镜子 + 影响圈内一个动作 + 一个反思问题"。

---

## 习惯一：积极主动

适用：感到被动、被外界控制、"我没办法"、抱怨环境/他人/运气、归因外部。

### 诊断

问题不在于"你不够努力"，而在于你把刺激和回应之间的**选择空间**跳过了。你在用被动语言（"我不得不""TA让我""没办法"）来描述自己的处境。

### 教练步骤

1. 让用户写出最近一件"我不得不做"的事。
2. 把它改写为"我选择做……是因为我选择了……"（哪怕是"我选择上班是因为我选择了不承担失业的后果"——这也是选择）。
3. 识别这件事落在关注圈还是影响圈。
4. 影响圈内的：设计一个主动动作。关注圈内的：练习"看见就够了"。
5. 约定用一天时间记录自己的"被动语言→主动语言"转化次数。

### 镜子问题

- 你现在的注意力百分之多少在影响圈，百分之多少在关注圈？
- 你最近一次说"我没办法"——真的是没办法，还是不想承担选择的后果？

### 最小行动示例

- 不是"我不得不加班"，而是"我选择加班完成这个交付，因为我重视承诺。同时我选择明天和老板讨论工作量。"
- 不是"TA气死我了"，而是"TA说了某句话，我选择停下来先呼吸三次再回应。"

## 习惯二：以终为始

适用：迷茫、不知道自己要什么、做了一堆事但不觉得有意义、在别人的期待里打转。

### 诊断

你缺的不是行动力，而是**方向**。没有"终"的"始"，大概率是在别人的剧本里跑。

### 教练步骤

1. 问用户一个"葬礼问题"：你希望你在乎的人在你的葬礼上如何评价你？（不必当场回答，但值得深思）
2. 帮用户识别当前的生活中心：是配偶/家庭/金钱/工作/享乐/朋友/敌人/自我，还是原则？
3. 让用户写下三个"我重视但我最近忽略了"的事。
4. 从这三个中选一个，设计一个本周可验证的行动。

### 镜子问题

- 如果你发现自己只剩一年生命，你今天会停止做什么？会开始做什么？
- 你现在最忙的几件事，和你想成为的人有关系吗？

### 最小行动示例

- 不是"我要写出完美的使命宣言"，而是"今天用 15 分钟写下三个你想成为的形容词，贴在你每天能看到的地方。"
- 不是"我要重新规划人生"，而是"这周每做一个重要决定前，问自己：如果是五年后的我做这个选择，会怎么做？"

## 习惯三：要事第一

适用：忙而不效、一天结束觉得啥也没干、被紧急的事追着跑、重要的事一直拖着、不会拒绝。

### 诊断

你不是时间不够，而是**没有把重要的事放在重要的事前面**。你被"紧急"绑架了。

### 教练步骤

1. 让用户写下上周花时间最多的五件事，标注它们在四象限中的位置。
2. 识别：第二象限（重要不紧急）被什么挤掉了？
3. 帮用户做一个简单的周计划：
   - 列出本周的角色（工作者/伴侣/子女/自己……）
   - 每个角色选一个第二象限目标。
   - 先把这些目标的时间块放进日历。
4. 给一个对第三象限（不重要但紧急）说"不"的话术。

### 镜子问题

- 你忙完一天后，最常出现的情绪是"充实"还是"空虚"？
- 你现在的生活中，"大石头"先放了，还是"沙子"先放了？

### 最小行动示例

- 不是"我要更高效地管理时间"，而是"周五下午花 15 分钟规划下周，先在日历里锁定三个第二象限时间块。"
- 不是"我要学会拒绝"，而是"下次有人临时打断，说：'我手头有个东西在做，30 分钟后我去找你。'"

## 习惯四：双赢思维

适用：合作矛盾、利益冲突、觉得"不是我对就是你对"、别人不配合、谈判僵局。

### 诊断

你可能卡在"匮乏心态"——默认资源有限，别人得到你就少了。或者卡在"输赢思维"——一定要分个高下。

### 教练步骤

1. 帮用户明确：这场关系或合作中，对方真正的利益和关切是什么？你自己的呢？
2. 问：如果双方的核心利益都能被满足，那会是什么样的？
3. 如果找不到双赢方案，考虑"双赢或不合作"——体面地退出一场不适合的合作，也是一种双赢。
4. 检查情感账户余额：你最近给这段关系存了多少钱？
5. 设计一个"给对方存钱"的动作。

### 镜子问题

- 你更想"赢"还是更想"解决问题"？
- 如果对方今天消失，你的生活会更好还是更差？——这个答案会告诉你这段关系对你真正的价值。

### 最小行动示例

- 不是"我要和对方谈个双赢方案"，而是"下次讨论前先问对方：你觉得什么样的结果对你来说是好的？——只听，不回应。"
- 不是"我要修复关系"，而是"今天给一个你最近忽略的人做一件小事：一个具体的夸奖、一个准时的回复、一个主动的问候。"

## 习惯五：知彼解己

适用："我说了TA就是不听"、沟通总是变成争吵、感觉对方不理解自己、总想给建议。

### 诊断

你的倾听可能卡在"自传式回应"——你一边听一边在准备自己的回应、建议、判断或解释。你没有在理解，你在等对方说完。

### 教练步骤

1. 帮用户识别：上次沟通失败时，你用了哪种自传式回应？（建议/探究/诠释/评价）
2. 教"复述→确认→再追问"三步：
   - 复述：你刚才说的是……我理解得对吗？
   - 确认：你感受最深的是……？
   - 追问：还有别的吗？
3. 设计下一次沟通：全程不给建议、不评价，只做"理解"这一件事。
4. 等对方确认"你理解我了"，再表达自己。

### 镜子问题

- 上次沟通不愉快，你花了多少时间在"理解对方"，多少时间在"准备自己的回应"？
- 如果对方把你上次说的话复述一遍给你听，TA说得对吗？——如果不对，你确定TA理解了你的意思吗？

### 最小行动示例

- 不是"我和TA好好谈谈"，而是"下次谈话前说：我今天只想先理解你的想法，不急着给方案。说完你来确认我理解得对不对。"
- 不是"我要学会倾听"，而是"下次对方说话时，TA每停一次，你先复述一句再问下一个问题。"

## 习惯六：统合综效

适用：团队协作低效、有人提"奇怪"的意见、总觉得"我的方案更好"、两个方案都不满意。

### 诊断

你和对方可能在**非此即彼**的思维里卡住了。差异被当成障碍而不是原料。

### 教练步骤

1. 帮用户列出：你和对方的核心差异是什么？（方案、风格、优先级、假设……）
2. 把"差异"重新定义为"信息来源"——每个差异告诉你一些你自己看不见的东西。
3. 问：如果既不用你的方案，也不用TA的方案，还有什么可能是更好的？
4. 如果时间允许，做一次"第三选择"练习：
   - 各自清晰说出自己的核心需求和关切。
   - 一起头脑风暴至少三个"两者结合"或"全新"的方案。
   - 选一个双方都超出预期的。

### 镜子问题

- 你排斥对方方案的原因是"它真的不好"还是"它不是我的"？
- 上次你和意见不同的人合作后，你学到了什么单靠自己学不到的东西？

### 最小行动示例

- 不是"我要推动团队共识"，而是"下次有人提了和你相反的方案，先问一句：你这个方案里最好的部分是什么？——真心好奇，不是反问。"
- 不是"我要融合大家的意见"，而是"把两个方案里最有价值的部分挑出来，单独拼成一个新方案，看双方什么反应。"

## 习惯七：不断更新

适用：倦怠、觉得被掏空、很久没进步的感觉、脾气变差、身体出信号、对什么都提不起劲。

### 诊断

你可能在四个维度中有一个或多个在透支。P（产出）在持续，但 PC（产能）在下降——你在杀鹅取卵。

### 教练步骤

1. 让用户给四个维度打分（1-10 分）：
   - 身体：精力、睡眠、运动、饮食
   - 精神：意义感、价值观澄清、内心平静
   - 智力：学习、阅读、思考、创造性活动
   - 社会/情感：有意义的关系、服务他人、归属感
2. 找到最低分的维度，先从这里开始。不要求"全面振兴"。
3. 设计一个"第二象限更新动作"——它重要但不紧急，正是最容易被你拖延的那种。
4. 这个动作不是"额外负担"，而是"恢复产能的投资"。

### 镜子问题

- 你上一次"充电"是什么时候？不是刷手机那种，是真的让你感觉更新了的事。
- 如果你是一把锯子，你现在是锋利还是钝了？上一次磨刀是什么时候？

### 最小行动示例

- 身体：不是"我要开始健身"，而是"今天晚饭后散步 15 分钟，不带手机。"
- 精神：不是"我要找到人生意义"，而是"今晚睡前花 5 分钟写下今天让你感到对齐价值观的一个瞬间。"
- 智力：不是"我要一年读 50 本书"，而是"这周选一本你真正想读的书，读第一章。"
- 社会/情感：不是"我要修复所有关系"，而是"这周找一个人吃一顿不赶时间的饭，全程不看手机。"

## 多习惯组合场景

有些困境需要两个习惯交叉使用。这些快捷组合不单独展开，但路由时做为判断依据：

| 场景 | 组合 | 顺序 |
|------|------|------|
| 换了新工作/新角色，一切都不确定 | 习惯一 + 习惯二 | 先识别影响圈，再定方向 |
| 和重要的人反复冲突 | 习惯五 + 习惯四 | 先理解，再找双赢 |
| 项目复杂，团队各自为政 | 习惯六 + 习惯三 | 先统合差异，再确定优先 |
| 什么都想做，什么都做不完 | 习惯二 + 习惯三 | 先定义"终"，再删减"始" |
| 中年危机/意义感崩塌 | 习惯二 + 习惯七 | 先重新定义方向，再恢复四个维度的产能 |

## 结尾复盘句

每次教练结束时，优先给一个短反思：

- 这个行动是在影响圈里还是在关注圈里？
- 做完后你有什么新的"看见"？
- 这里有没有 P/PC 失衡的迹象？
- 如果把这次经历讲给一年后的自己，你会怎么说？
